# 五子棋游戏 · 设计与实现说明

单文件网页版五子棋（Gomoku / 五子连珠），**人机对战**为主，同时支持双人对弈。
实现：`index.html`（一个文件，双击用浏览器打开即可，零依赖）。

---

## 一、交互与操作设计（操作 / 界面 / 流程）

### 1.1 界面布局
```
┌───────────────────────────────────────────────┐
│  标题：五子棋   副标题：15×15 · 五连为胜         │
├───────────────────────────────────────────────┤
│  控制栏：                                       │
│  对局模式：[人机对战 ▾]  难度：[普通 ▾]          │
│  先手：[我执黑先 ▾]  (仅人机模式)                │
├───────────────────────────────────────────────┤
│  状态栏：轮到你落子（执黑） / 电脑思考中…        │
│  图例：● 你(黑)   ○ 电脑(白)    走子数：0        │
├───────────────────────────────────────────────┤
│                 ┌─────────────┐                │
│                 │   15×15     │  落子棋盘      │
│                 │   棋盘      │  (Canvas)      │
│                 └─────────────┘                │
│  结果横幅：🎉 你赢了！ / 😾 电脑赢了 / 平局     │
│            [ 再来一局 ]                         │
├───────────────────────────────────────────────┤
│  [重开] [悔棋] [认输]  [🔊声音]  [?帮助]        │
└───────────────────────────────────────────────┘
```

### 1.2 操作项清单（全部操作）
| 操作 | 触发方式 | 说明 |
|---|---|---|
| 落子 | 点击 / 触摸棋盘空格 | 人先手时点击落子；非当前方点击无效 |
| 切换对局模式 | 下拉：人机对战 / 双人对弈 | 切换后自动重开 |
| 调整难度 | 下拉：简单 / 普通 / 困难 | 仅人机模式有效，从下一手起生效 |
| 选择先手 | 下拉：我执黑先 / 我执白后 | 仅人机模式；选"白后"则电脑先落 |
| 重开新局 | 按钮 / `R` / 结果横幅按钮 | 清空棋盘重置 |
| 悔棋 | 按钮 / `U` | 人机模式撤销"电脑+你"各一步；双人撤销一步；可悔败 |
| 认输 | 按钮 | 当前方判负 |
| 开关音效 | 按钮 / `M` | 落子"啪"声（WebAudio，默认关） |
| 帮助 | 按钮 / `?` | 展开规则 / 快捷操作说明 |
| 走法动画 | 自动 | 落子显示"最后一步"标记；胜方连线高亮 |
| 预览落子 | 鼠标悬停空格 | 半透明"幽灵子"提示将要落的颜色 |

### 1.3 关键流程
- **开局**：默认"人机对战 / 普通难度 / 我执黑先"。点"开始/重开"或首次加载即进入。
- **落子回合**：`你落子 → 判定胜负/平局 → 轮到电脑 → 电脑"思考"(300~500ms 防抖) → 电脑落子 → 回到你`。思考中禁止点击，状态显示"电脑思考中…"。
- **胜负判定**：每次落子后沿 4 个方向（横/竖/正斜/反斜）检查是否形成 5 连；命中即判胜并高亮连线；棋盘填满则平局。
- **结果**：弹出横幅，"再来一局"一键重开。
- **悔败**：即使已判负，悔棋可撤销回到上一步重新下（体验更友好）。
- **边界/异常**：非当前方、思考中、已结束的点击全部忽略；点击格越界或已有子则忽略；AI 找不到手时判平局。

## 二、代码设计与算法

### 2.1 技术选型
- **单文件 HTML + Canvas + 原生 JS**：可双击打开、可整文件分享（如通过 IM 的 `[file:]` 标记），无任何依赖与打包。
- 棋盘用 **Canvas** 绘制（清晰、易做悬停预览/连线高亮）；UI 控件用 HTML。
- 响应式：`aspect-ratio:1` + 最大宽度，小屏自适应；坐标按显示尺寸比例换算，支持鼠标与触摸。

### 2.2 数据模型
```js
state = {
  board:  15×15 二维数组,     // 0 空, 1 黑, 2 白
  turn:   黑/白,              // 当前该谁落子
  human, ai: 颜色,            // 人机模式下各自动作颜色
  mode:   'ai' | 'pvp',
  diff:   'easy'|'medium'|'hard',
  history: [{r,c,color}],     // 记录所有走子，悔棋/重画用
  over, winner, winLine,      // 结束状态与胜方连线
  thinking, sound
}
```
常数：棋盘 15×15，绘制参数 间距 G=40、边距 P=24、子圆半径 ≈ 0.45·G。

### 2.3 核心逻辑
- **落子 `place(r,c,color)`**：合法性校验 → 写入 `board/history/moves` → 音效 → 判胜负/平局 → 切换回合 → 若轮到 AI 则调度 `scheduleAI()` → 重绘 + 更新状态。
- **胜负 `findWinningLine(board,r,c,color)`**：从新落子出发，沿 4 个方向统计连续同色子数，≥5 返回这 5+ 个坐标（用于高亮）。
- **平局**：`moves === 15×15` 且无人成五连。

### 2.4 电脑（AI）策略
在"靠近已有棋子"的候选子点里（切氏距离 ≤2 邻域）做评分，分 4 个优先级层：
1. **绝杀优先**：己方存在一步成 5 连 → 直接落该子。
2. **封堵优先**：否则若对方有一步成 5 连 → 堵。
3. **启发式评分**：对每个候选点，沿 4 方向用"连续子数 + 两端是否开放"的**形态表**打分，攻击分×权重 + 防守分×权重 + 轻微居中偏好，取最优。
   ```
   形状表(连续数 count, 开放端数 open)：
   五连         → 1,000,000      (绝杀)
   活四/冲四    → 100,000 / 10,000
   活三/眠三    → 5,000  / 500
   活二/眠二    → 300    / 30
   活一/眠一    → 10     / 1
   由于 4 方向得分相加，一步同时形成两个威胁（如双活三 / 四三）会拿到双倍分，
   从而天然识别并优先走出"双威胁(分叉)"。
   ```
4. **难度差异**：
   - **简单**：权重压低 + 从 Top-4 中加权随机选，会下出"软招/失误"，新手易赢。
   - **普通**：标准权重，直接取最优解。
   - **困难**：在最优解基础上做 1 层"威胁搜索"——对 Top-10 候选各试一手，估算对方最优反着分，扣减该分，从而避免把"双威胁/绝杀"让给对方，棋力明显更强。
   第一手固定落到天元（中心 `(7,7)`）。

### 2.5 渲染
- 木纹背景 + 15×15 网格线 + 5 个星位（`3/7/11` 十字交点）。
- 棋子用径向渐变做立体感（黑/白）。
- 最新落子画"环/点"标记；胜方 5 连画红色高亮线。
- 悬停时在当前方颜色上画半透明"幽灵子"预览。

## 三、文件说明

## 四、可扩展点
- 加棋盘大小切换（13/15/19）、禁手（黑白分别规则）、联机版。
- 强化 AI：可把"困难"的 1 层搜索扩展为 Alpha-Beta 搜索 2~3 层（棋力进一步提升）。
- 加"复盘/历史回放"、保存对局、主题皮肤。
